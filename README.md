# Web App Experiments

This repository contains a collection of web application experiments developed as part of web development practice and academic coursework.

## Experiments

### 1. Portfolio Website

Develop a personal portfolio website that provides details about yourself for potential recruiters. The website can include personal information, career objective, education, technical skills, projects, achievements, contact details, and other relevant professional information.

**Key Features:**
- Personal profile
- Career objective
- Educational details
- Technical skills
- Projects
- Achievements
- Contact information
- Responsive design

---

### 2. To-Do List Application

Create a web application to manage the TO-DO list of users, where users can login and manage their to-do items.

**Key Features:**
- User registration and login
- Add new tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Manage personal to-do items

---

### 3. Micro Blogging Application

Create a simple micro blogging application like Twitter that allows people to post their content which can be viewed by people who follow them.

**Key Features:**
- User registration and login
- Create posts
- View posts
- Follow users
- User profiles
- Feed management

---

### 4. Food Delivery Website

Create a food delivery website where users can order food from a particular restaurant listed on the website.

**Key Features:**
- Restaurant listing
- Food menu
- Food item selection
- Shopping cart
- Order placement
- User login and registration
- Order management

---

### 5. Classifieds Web Application

Develop a classifieds web application to buy and sell used products.

**Key Features:**
- User registration and login
- Browse products
- Search products
- View product details
- Post used products for sale
- Manage personal listings

---

### 6. Leave Management System

Develop a leave management system for an organization where users can apply for different types of leaves such as casual leave and medical leave. Users can also view the available number of leave days.

**Key Features:**
- User login
- Apply for leave
- Casual leave
- Medical leave
- View leave balance
- View leave status
- Leave management

---

### 7. Project Management Dashboard

Develop a simple dashboard for project management where the statuses of various tasks are available. New tasks can be added and the status of existing tasks can be changed among Pending, In Progress, or Completed.

**Key Features:**
- Dashboard
- Add new tasks
- View tasks
- Update task status
- Pending status
- In Progress status
- Completed status
- Task management

---

### 8. Online Survey Application

Develop an online survey application where a collection of questions is available and users are asked to answer any random 5 questions.

**Key Features:**
- Collection of questions
- Random question selection
- Display 5 random questions
- Submit answers
- Survey completion

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL
- Responsive Web Design

## How to Run

1. Download or clone this repository.
2. Open the required experiment folder.
3. For HTML/CSS/JavaScript projects, open the `index.html` file in a web browser.
4. For PHP projects, place the project folder inside the XAMPP `htdocs` directory.
5. Start Apache and MySQL from XAMPP if required.
6. Open the application using:

```text
http://localhost/project-folder/
